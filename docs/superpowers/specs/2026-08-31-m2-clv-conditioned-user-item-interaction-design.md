# M2 CLV 조건부 사용자–상품 결합 표현 설계

## 1. 연구축과 질문

이 설계는 M1~M5 중 **M2 임베딩·표현 개입**에 해당한다. 그래프, 표본추출,
손실함수는 M1과 동일하게 유지한다.

연구질문은 다음과 같다.

> 기존 LightGCN의 2층 협업표현을 유지하면서, 학습기간 historical CLV
> proxy의 전체 수준과 N/V 구성 차이가 하나의 사용자–후보상품 결합 표현을
> 조건화하도록 하면, 저·중CLV 성능을 훼손하지 않고 고CLV 고객의 신규상품
> 순위를 개선할 수 있는가?

이 질문은 고CLV 고객에게 얕은 전파를 적용하는 가설과 다르다. 전파 깊이
진단에서 Dunnhumby와 H&M 모두 0·1·2층 평균이 우세했으므로 LightGCN의
표준 2층 평균은 고정한다.

## 2. 선행 실패에서 고정할 설계 원칙

1. 전체 CLV 스칼라만으로 상품을 선택하지 않는다.
2. N과 V가 독립적인 상품점수를 만든 뒤 합산되지 않게 한다.
3. 사용자 CLV로 모든 후보상품에 같은 배율을 적용하지 않는다.
4. `RepeatShare`, 상품 인기도, 가격·상품군 같은 별도 후보 입력을 추가하지
   않는다. 이번 실험은 CLV 조건부 협업표현 자체만 검정한다.
5. 기존 LightGCN의 0·1·2층 평균을 줄이거나 교체하지 않는다.
6. 학습형 전체 축 가중치 `s_N`, `s_V`를 두지 않는다.
7. CLV 경로는 같은 forward graph와 같은 BPR 손실 안에서 ID 임베딩과 함께
   학습한다. 학습 완료 점수에 외부 보정 또는 재정렬을 하지 않는다.

## 3. 고정 historical CLV 입력

사용자 `u`의 학습기간 행동에서 기존 연구 정의에 따라 다음을 계산한다.

\[
C_u^{hist}=\widehat N_u\widehat V_u
\]

여기서 `N_hat`은 반복거래 정도를 반영한 행동기반 추정치이고, `V_hat`은
거래당 가치 수준을 반영한 행동기반 추정치다. 미래 CLV나 추천 이후 증가한
가치를 의미하지 않는다.

전체 수준은 train 사용자 분포에서만 백분위로 바꾼다.

\[
q_C(u)=\operatorname{Percentile}_{train}(C_u^{hist})\in[0,1]
\]

N/V 구성은 두 축의 train 백분위 차이로 둔다.

\[
d_u=q_N(u)-q_V(u)\in[-1,1]
\]

- `d_u > 0`: N우세
- `d_u < 0`: V우세
- `d_u ≈ 0`: 균형

`q_C`는 전체 CLV 개입 크기를 정하고, `d_u`는 같은 CLV 수준 안에서 가치가
형성된 구성을 구별한다. N과 V는 독립 점수를 만들지 않는다.

입력 계산이 불가능한 축은 유효성 마스크로 0 처리하고, 백분위와 마스크는
학습기간에서 고정해 평가 시 다시 추정하지 않는다.

## 4. 표준 LightGCN 협업표현

사용자와 상품의 자유 ID 임베딩을 하나의 이진 사용자–상품 그래프에서
2층 전파한다.

\[
E^{(l+1)}=\widehat A E^{(l)}
\]

\[
z=\frac{1}{3}\left(E^{(0)}+E^{(1)}+E^{(2)}\right)
\]

사용자 표현을 `z_u`, 상품 표현을 `z_i`로 쓴다. 이 64차원 블록은 M1의
협업표현이며 CLV 경로 때문에 차원을 줄이지 않는다.

## 5. CLV 조건부 사용자–상품 결합 표현

### 5.1 작은 결합공간

협업표현을 `r=4` 차원의 공유 결합공간으로 투영한다.

\[
h_u=\operatorname{Unit}(P_u z_u),\qquad
h_i=\operatorname{Unit}(P_i z_i)
\]

- `P_u`, `P_i`: 추천손실로 공동학습되는 선형 투영
- `Unit(x)=x/max(||x||_2,10^-12)`: 0 나눗셈을 막는 행별 L2 정규화
- 별도의 N 상품 임베딩이나 V 상품 임베딩은 만들지 않는다.

### 5.2 전체 CLV 방향과 N/V 구성

전체 CLV의 공통 조건과 N/V 구성에 따른 변화 방향을 하나의 문맥벡터로
결합한다.

\[
h_C(u)=\operatorname{Unit}\left(w_C+d_u w_D\right)
\]

- `w_C`: 전체 CLV 조건의 공유 방향
- `w_D`: N우세와 V우세에 따라 공유 방향을 조절하는 방향
- 두 벡터 모두 `r=4`이며 동일한 BPR 손실로 학습

### 5.3 세 요소의 결합

사용자, 후보상품, CLV 조건이 모두 있을 때만 생기는 결합표현을 만든다.

\[
a_u=q_C(u)\,h_u\odot h_C(u)
\]

후보상품별 CLV 조건부 관계는 다음 한 값이다.

\[
R(u,i,C_u)=a_u^\top h_i
\]

성질은 다음과 같다.

- 같은 `q_C,d`를 가진 고객도 `h_u`가 다르면 다른 후보상품을 선택한다.
- 같은 고객도 `h_i`가 다르면 후보상품마다 다른 보정을 받는다.
- `q_C=0`이면 CLV 경로가 0이 된다.
- N과 V는 두 점수로 분리되지 않고 `h_C` 안에서 하나의 방향을 만든다.
- `h_u`, `h_i`, `h_C`가 단위벡터이므로 `|R|≤q_C≤1`이다.

### 5.4 하나의 임베딩과 하나의 내적

실제 구현은 학습 완료 후 외부 점수를 더하지 않는다. 최종 사용자·상품
표현을 다음처럼 확장한다.

\[
\widetilde z_u=
\left[z_u\;\middle|\;\sqrt{\rho}\,a_u\right]
\]

\[
\widetilde z_i=
\left[z_i\;\middle|\;\sqrt{\rho}\,h_i\right]
\]

\[
S_{M2}(u,i)=\widetilde z_u^\top\widetilde z_i
=z_u^\top z_i+\rho R(u,i,C_u)
\]

`rho=0.05`는 사전에 고정하며 학습하지 않는다. `|rho*R|≤0.05`이므로 학습형
`s_N,s_V`처럼 축 강도가 무제한 커지는 경로가 없다.

## 6. 학습과 불변 조건

- 그래프: M1과 동일한 binary 사용자–상품 그래프
- 전파: LightGCN 2층, 0·1·2층 단순평균
- negative sampling: uniform
- 목적함수: 기존 plain pairwise BPR와 기존 sampled L2만 사용
- BPR 표본 가중: 없음
- 새 손실항: 없음
- optimizer: 하나
- 학습루프: 하나
- 최소 아이템 상호작용: 1
- 학습 epoch: 100 고정
- validation 기반 epoch 선택: 없음
- 사용자·상품 ID 임베딩, `P_u`, `P_i`, `w_C`, `w_D`를 동시에 학습

## 7. 빠른 역사적 개발 실험

### 7.1 1차 실행

- 데이터: Dunnhumby
- seed: 42
- 학습: day 1~683
- 개발평가: day 684~690 신규상품 추천
- 최종 test와 holdout: 생성·평가하지 않음
- 학습구간에 존재한 `(user,item)` 쌍은 평가 정답과 후보에서 제외

첫 실행은 다음 두 arm을 같은 러너에서 학습한다.

1. `rho=0`: 동일 초기화·동일 구조·동일 난수소비의 비개입 대조군
2. `rho=0.05`: CLV 조건부 사용자–상품 결합 표현

외부 저장 M1@64는 절대 성능 확인용으로 함께 표시하되, CLV 효과의 직접
판정은 동일 러너의 `rho=0` 대조군을 기준으로 한다.

### 7.2 긍정 판정 기준

다음 조건을 모두 만족해야 1차 탐색을 통과한다.

1. 전체 Recall/NDCG@10·20·50이 `rho=0`의 99% 이상
2. 고CLV Recall@10과 NDCG@10이 모두 `rho=0`보다 증가
3. 전체 가격·구매금액 가중 적중값@10이 `rho=0` 이상
4. 고CLV 사용자의 Top-10 집합이 실제로 바뀐 비율이 0이 아님
5. `rho=0` arm이 동일 러너의 CLV 비개입 표현과 수치적으로 일치

단일 seed 탐색이므로 통계적 유의성을 주장하지 않는다.

### 7.3 통과 후 대조군

1차 실행이 통과한 경우에만 다음을 수행한다.

1. 동일 총 차원 M1 대조군
2. shuffled-user CLV 대조군
3. `q_C`만 사용하고 `d_u=0`으로 둔 전체 CLV 대조군
4. 여러 seed
5. H&M 2년 동일 구조 실행

정상 CLV 배정이 shuffled-user보다 낫지 않으면 CLV 기여를 주장하지 않는다.
`q_C,d_u` 조건이 `q_C` 단독보다 낫지 않으면 N/V 구성 분리의 기여를
주장하지 않는다.

## 8. 필수 작동 진단

성과를 해석하기 전에 다음을 저장한다.

- `std(rho*R) / std(S_ID)`: 실제 CLV 점수 영향력
- `mean(|rho*R|)`와 최대값
- 전체·저·중·고CLV별 Top-10 변경 사용자 비율
- `q_C`와 사용자별 평균 `|R|`의 Spearman 상관
- N우세·균형·V우세별 `R` 평균과 표준편차
- 공동학습된 ID-only 성과와 full 성과
- `w_C`, `w_D` 코사인 유사도
- 사용자 결합표현 모집단 평균 norm / 평균 사용자 norm

판독은 다음과 같다.

- 점수 영향력이 거의 0이고 추천목록이 같음: 실효 개입 실패
- ID-only는 개선되지만 full이 악화: CLV 경로가 공동학습 ID 이득을 훼손
- full이 개선돼도 shuffled-user와 동일: CLV 배정 효과 없음
- `w_C`와 `w_D`가 사실상 동일하고 `q_C` 단독과 같음: N/V 구성 기여 없음
- 전체 정확도 가드 미달: 고CLV 일부 개선이 있어도 1차 탈락

## 9. 과거 기각 구조와의 차이

이 설계는 다음을 다시 사용하지 않는다.

- `S_N+S_V` 독립 점수 합산
- `g_N(u),g_V(u)`의 독립 사용자 게이트
- `s_N,s_V` 학습형 전체 축 가중치
- `RepeatShare` 또는 상품 인기도 입력
- 상품군·가격 구매이력 보조 블록
- CLV별 전파 깊이 감소
- 완성된 M1 점수의 외부 재정렬

새 검정요소는 **전체 CLV 수준이 개입 크기를 정하고 N/V 구성은 하나의
문맥방향만 조절하며, 그 문맥이 기존 사용자·후보상품 협업표현과 저차원에서
세 방향 곱으로 결합되는 것**이다. 문헌상 설명은 새로운 이름을 만들지 않고
`context-aware tensor factorization` 또는 `context-conditioned interaction`의
기존 용어를 사용한다.

## 10. 한계

- historical CLV proxy는 사용자마다 학습기간에 고정되어 자유 사용자 ID
  임베딩에 일부 흡수될 수 있다. matched `rho=0`, ID-only, shuffled-user
  대조가 필요하다.
- 고CLV 성능을 보고 설계한 역사적 개발 실험이므로 동일한 최종 test를 열어
  재선택하지 않는다.
- 단일 seed 결과는 구조의 작동 여부만 확인하며 일반화나 유의성을 주장하지
  않는다.
- 이 구조가 실패하면 전체 CLV와 N/V 구성을 더 복잡한 MLP나 더 큰 결합차원에
  넣는 방식으로 즉시 확장하지 않는다. 실패 원인을 먼저 분해한다.
