# M5: CLV 경제표현과 양성 구매금액 가중학습 결합 설계

**작성일:** 2026-09-05

**상태:** 구현 전 검토안

**연구축:** M5 부분 결합(M2 표현 + M4 손실)

**첫 실행:** Dunnhumby historical development, seed 42, validation screen

## 1. 답하려는 연구질문

이 실험은 다음 한 문장을 검정한다.

> 고객의 historical CLV 관련 경제성향을 사용자·상품 표현에 제공하고,
> 구매금액이 큰 양성 상호작용을 같은 추천손실 안에서 더 중요하게 학습하면,
> 일반 정확도를 유지하면서 가격·구매금액 가중 추천 적중 성과가 기준모형보다
> 높아지는가?

M2, M3, M4는 여전히 동등한 연구축이다. 이 실험은 M2와 M4의 부분 결합인
M5이며 M3를 대체하지 않는다.

## 2. 기존 M5와 다른 가설

이전 M5-v1/v2는 M2 경제표현과 CLV 조건부 hard-negative 학습을 결합했다.
두 실행에서 가격·구매금액 가중 적중값@10의 상호작용은 각각 -0.008480,
-0.004341이었다. 다만 이 결과만으로 M2가 올린 상품을 hard negative가
직접 억눌렀다고 단정하지 않는다. M5-v2에서 ID 점수와 전체 점수가 선택한
hardest negative의 불일치율이 약 0.38%였으므로, 그 억제 경로는 충분히
작동하지 않았을 수도 있다.

이번 실험의 새 가설은 다음과 같다.

- 음성 선택은 바꾸지 않는다.
- 실제 구매된 양성 상품의 학습구간 경제값이 클수록 손실 가중치를 높인다.
- M2 경제표현이 그 방향을 학습할 유인을 손실에서 직접 제공한다.
- 따라서 M2와 M4의 경제적 상호작용이 양수가 되는지를 검정한다.

이는 2026-08-18의 `CLV×상품기여도` 재실행이 아니다. 당시 상품기여도는
과거 사용자-상품 장바구니 기여율로 신규상품에 적용할 수 없었다. 이번 값은
학습구간에서 모든 후보상품에 정의되는 상품 대표 구매금액 백분위이므로 신규상품
후보에도 적용된다.

## 3. 고정 과업과 데이터 경계

- 과업: 신규상품 추천
- 평가 정답: 학습구간에 존재한 `(user, item)` 쌍 제외
- 그래프: M1과 동일한 binary 사용자-상품 그래프
- 최소 상품 상호작용: 1
- 음성 샘플링: 균등분포, 양성당 5개
- 전파층: 2층
- 최종 epoch: 100, epoch 선택 없음
- 첫 실행: Dunnhumby day 683까지 학습, day 684~690 개발평가
- final test와 별도 holdout은 생성하지 않음
- 사용자 historical CLV proxy와 모든 경제 입력은 학습구간에서만 계산

## 4. 공통 입력 정의

### 4.1 사용자 CLV 수준

기존 연구 정의를 유지한다.

\[
q_C(u)=\operatorname{Percentile}(\widehat N_u\widehat V_u)\in[0,1].
\]

`q_C`는 M4의 양성 손실 가중치에만 사용한다. CLV 수준 자체가 어떤 상품을
고를지 결정하지 않고, 경제적으로 큰 양성을 얼마나 강조할지만 결정한다.

### 4.2 차수를 통제한 V 구성 정보

기존 `q_V`와 활동량의 중복을 줄이기 위해 학습 사용자 degree 10분위 안에서
V 백분위의 분위내 순위를 구한다.

\[
v_u^{cond}=2\operatorname{PercentileWithinDegreeDecile}(q_V(u))-1.
\]

이는 엄밀한 직교화라고 부르지 않고 **degree-conditioned V rank**라고 부른다.
유효한 V 입력이 없는 사용자는 0으로 둔다.

### 4.3 상품의 대표 구매금액 백분위

상품별로 학습구간 구매행의 `purchase amount` 중앙값을 구한다. Dunnhumby는
`금액/수량`이 아니라 실제 구매행 금액을 사용하고, H&M은 수량이 1이므로
거래가격과 같다. 극단값 영향을 줄이기 위해 로그 변환 후 전체 상품 내
백분위를 계산한다.

\[
a_i=\operatorname{Percentile}_i\!\left(
\log(1+\operatorname{Median}_{(u,t)\in train}\operatorname{Amount}_{uit})
\right).
\]

카테고리 내에서도 같은 값을 다시 백분위화한다.

\[
a_i^{cat}=\operatorname{Percentile}_{j:\,cat(j)=cat(i)}(a_j).
\]

두 데이터에 동일한 계산 규칙을 사용한다. 다만 카테고리 세분성 차이는 결과
해석에 명시한다. 유효 가격/금액이 없는 상품은 전체 및 카테고리 백분위를
0.5로 두어 중심화 후 비개입이 되게 한다.

### 4.4 축소추정 사용자 경제분포

상품을 `a_i` 기준 4개 동일 상품수 구간으로 나눈다. 사용자가 각 구간에서
사용한 구매금액의 비율을 `p_u`로 계산하고, 관측이 적은 사용자는 전체
모집단 분포로 축소한다.

\[
\widetilde p_u=
\frac{n_up_u+\kappa\bar p}{n_u+\kappa},\qquad \kappa=10.
\]

모집단 평균을 빼서 중심화한다.

\[
p_u^{centered}=\widetilde p_u-\bar p.
\]

구간 수 4, 상품수 기준 구간, `kappa=10`은 첫 실행 전에 고정하며 결과를 본
뒤 바꾸지 않는다.

## 5. M2 경제표현

### 5.1 입력과 투영

사용자 경제 입력은 4구간 중심화 분포와 degree-conditioned V rank를 함께 쓴다.

\[
x_u^E=[p_u^{centered}\mid v_u^{cond}]\in\mathbb R^5.
\]

상품 경제 입력은 전체와 카테고리 내 대표 구매금액 위치다.

\[
x_i^E=[2a_i-1\mid 2a_i^{cat}-1]\in\mathbb R^2.
\]

각각 작은 학습형 투영을 거친다. Bound4(y)=tanh(y)/2로 정의하면
각 좌표는 [-0.5, 0.5], 4차원 벡터 norm은 최대 1이다.

\[
h_u^E=\operatorname{Bound4}(W_Ux_u^E),\quad W_U\in\mathbb R^{4\times5},
\]

\[
h_i^E=\operatorname{Bound4}(W_Ix_i^E),\quad W_I\in\mathbb R^{4\times2}.
\]

투영층에는 bias를 두지 않는다. 중심화 입력이 0이면 경제표현도 정확히 0이
된다. 행별 단위 정규화는 사용하지 않는다. 단위 정규화는 축소추정으로
작아진 희소 사용자 입력도 다시 크기 1로 키우므로 H&M의 자동 비개입
의도와 충돌한다. Bound4는 입력 크기를 보존하면서 학습형 투영의 최대
개입 크기만 구조적으로 제한한다.

### 5.2 LightGCN 내부 결합

경제표현은 완성된 M1 점수 뒤에 외부 재정렬로 더하지 않는다. ID 임베딩과
함께 layer-0 표현에 넣고 동일한 2층 binary LightGCN 전파를 통과시킨다.

\[
E_u^{(0)}=[E_u^{ID}\mid\sqrt\rho\,h_u^E],\qquad
E_i^{(0)}=[E_i^{ID}\mid\sqrt\rho\,h_i^E].
\]

\[
E^{(l+1)}=\widehat A E^{(l)},\qquad
Z=\frac{1}{3}\sum_{l=0}^{2}E^{(l)}.
\]

\[
S(u,i)=Z_u^\top Z_i.
\]

`rho=0.15`를 사전 고정한다. 제곱근은 사용자와 상품 양쪽에 같은 예산을
배분하여 layer-0 내적의 경제항 계수가 정확히 `rho`가 되게 한다. 경제 투영
파라미터와 ID 임베딩은 하나의 학습 루프·optimizer에서 같은 추천손실로
동시에 갱신한다.

## 6. M4': CLV 조건부 양성 구매금액 가중 BPR

각 양성 `(u,i^+)`에 대해 5개의 균등 음성 `i_k^-`를 사용한다.

\[
\ell_{uk}=\operatorname{softplus}
\left(S(u,i_k^-)-S(u,i^+)\right).
\]

양성 상품의 중심화 경제값은 다음과 같다.

\[
e(i^+)=2a_{i^+}-1\in[-1,1].
\]

원시 가중치는

\[
w_{ui^+}^{raw}=1+\lambda q_C(u)e(i^+),\qquad \lambda=0.5
\]

로 정의한다. 따라서 정규화 전 범위는 `[0.5, 1.5]`이고 부호가 뒤집히거나
음수가 되지 않는다. 균등하게 표본화되는 학습 고유엣지 전체에서 사전에 계산한
평균으로 나누어 평균 손실질량을 1로 고정한다.

\[
w_{ui^+}=\frac{w_{ui^+}^{raw}}
{\operatorname{Mean}_{(u,i)\in E_{train}}w_{ui}^{raw}}.
\]

최종 손실은 음성 점수의 평균과 양성 점수를 한 번 비교하는 식이 아니라,
각 음성별 BPR 손실을 먼저 계산한 뒤 평균한다.

\[
\mathcal L_{rank}=\sum_{(u,i^+)}w_{ui^+}
\frac1{5}\sum_{k=1}^{5}\ell_{uk}.
\]

정규화 분모는 고정 입력에서 미리 계산하며 gradient 대상이 아니다. 정규화항은
기존 M1과 같은 방식으로 더한다. hard-negative 선택은 사용하지 않는다.

## 7. 2×2 요인실험과 식별 대조군

| Arm | 표현 | 손실 | 답하는 질문 |
|---|---|---|---|
| A: M1-K5 | ID 64차원 | K=5 균등평균 BPR | 공통 기준 |
| B: M2 | ID + 경제표현 4차원 | K=5 균등평균 BPR | 표현 단독 효과 |
| C: M4' | ID 64차원 | CLV×양성 경제값 가중 BPR | 유인 단독 효과 |
| D: M5 | ID + 경제표현 4차원 | CLV×양성 경제값 가중 BPR | 결합 효과 |
| E: M5-shuffle | D와 동일 | D와 동일 | 올바른 사용자 경제정보 배정 효과 |
| F: M5-degree-gate | D의 실제 경제표현 | `q_C` 대신 사용자 degree 백분위 | 손실 gate가 단순 활동량인지 식별 |

E에서는 `(q_C, q_V, v^{cond}, p^{centered}, valid)`를 사용자 degree 10분위
안에서 하나의 tuple로 공동 순열한다. 사용자별 tuple 내부 관계는 유지하고
올바른 사용자 배정만 끊는다. 같은 순열을 표현과 손실에 사용한다.

F는 M2 경제표현을 유지한 채 M4'의 `q_C`만 학습 사용자 degree 백분위로
바꾸는 **loss-gate 대조군**이다. 따라서 F는 전체 CLV 정보 대조군이 아니라
`q_C`의 학습 우선순위 효과가 활동량으로 대체 가능한지를 답한다.

각 arm은 독립 초기화·독립 optimizer를 사용하되, 한 arm 안에서는 모든
표현 파라미터를 한 학습 루프에서 공동학습한다.

## 8. 주지표, 상호작용, 판정 규칙

### 8.1 주지표

주지표는 코드의 `vndcg@10`, 즉 **가격·구매금액 가중 NDCG@10**이다.
평가구간 신규상품 정답의 실제 구매금액을 gain으로 사용한다. 이는 CLV 증가나
증분매출을 뜻하지 않는다.

### 8.2 상호작용

\[
I=(D-C)-(B-A).
\]

`I>0`이면 M2 경제표현의 효과가 M4' 학습유인 아래에서 더 커졌음을 뜻한다.
상호작용은 결합모형이 기준보다 좋은지와 별개의 연구질문이므로 둘 다 보고한다.

### 8.3 첫 screen의 사전 성공조건

다음을 모두 만족해야 `positive_screen=true`로 기록한다.

1. D의 가격·구매금액 가중 NDCG@10이 A보다 높다.
2. D가 같은 지표에서 C보다 높다.
3. D가 같은 지표에서 E보다 높다.
4. D가 같은 지표에서 F보다 높다.
5. 주지표의 상호작용 `I`가 0보다 크다.
6. D의 Recall@10/20/50과 NDCG@10/20/50이 각각 A의 99% 이상이다.
7. D의 Coverage@10과 고유 추천상품 수가 A의 95% 이상이고,
   Top-10 집중도가 A의 105% 이하이다.

단일 seed 개발 screen이므로 통계적 유의성이나 일반화를 주장하지 않는다.
통과하면 같은 고정 설정으로 여러 개발 seed를 실행하고, 그 뒤 H&M seed 42로
이식한다. 실패해도 결과를 본 뒤 같은 실행에서 `rho`, `lambda`, 구간 수,
`kappa` 또는 판정기준을 바꾸어 재판정하지 않는다.

## 9. 개입 작동 진단

성과와 별개로 다음을 반드시 저장한다.

- `std(economic_score) / std(ID_score)`
- `std(w) / mean(w)`
- 사용자 CLV 구간별 평균·표준편차·최솟값·최댓값
- 경제표현 4차원의 사용자·상품 평균 norm
- 경제표현 각 입력열에 대한 투영 weight norm
- 추천 상품 평균 가격 백분위와 사용자 `q_V` 사분위별 값
- 사용자 degree 사분위별 추천 상품 평균 가격 백분위
- D와 E/F의 Top-10 변경 사용자 비율과 Jaccard
- `rho=0` arm의 경제 기여 최대 절댓값과 A parity

다음 두 값은 사전 **작동 확인선**이며 성공조건이 아니다.

- `std(economic_score)/std(ID_score) >= 0.02`
- `std(w)/mean(w) >= 0.10`

하나라도 미달하면 성과 실패로 단정하지 않고 `개입 불충분`으로 별도 기록한다.
그 경우에도 같은 결과를 재분류하거나 자동으로 강도를 바꾸지 않는다.

## 10. 구현 경계와 실패 처리

- M2 단독 arm B에서는 그래프, 음성표본, 손실가중을 바꾸지 않는다.
- M4' 단독 arm C에서는 사용자·상품 표현을 ID 64차원으로 유지한다.
- 외부 재정렬이나 평가시점 점수 합산은 사용하지 않는다.
- 경제입력과 CLV 입력은 모두 학습구간에서만 계산한다.
- 평가 정답, 오추천 분석, validation 결과를 입력이나 손실가중치에 사용하지 않는다.
- invalid 경제입력은 중심값으로 두어 비개입시킨다.
- M5가 좋아도 E/F를 이기지 못하면 CLV 고유 효과로 귀속하지 않는다.
- M5가 기준보다 좋지만 상호작용이 음수면 결합은 유효할 수 있으나 M2와 M4'가
  경제축에서 상보적이라는 가설은 기각한다.
- 모든 불리한 지표와 미달 조건을 함께 보고한다.
