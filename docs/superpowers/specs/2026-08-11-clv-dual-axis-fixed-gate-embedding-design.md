# CLV 이중축 고정 게이트 임베딩 설계

## 1. 연구 위치와 목적

본 모형은 LightGCN의 사용자·아이템 표현에 CLV 관련 정보를 반영하는 **M2 임베딩
개입**이다. 이진 그래프와 plain BPR은 M1과 같게 유지하여 M3 가중그래프와 M4 CLV 가중
손실과 분리한다.

선행연구의 비계약형 CLV 구조인 `미래 거래횟수 × 미래 거래당 가치`를 두 사용자
표현으로 분리하고, 각 축에 대응하는 아이템 표현과 결합한다. 두 데이터셋에 동일한 모형
구조를 적용하되, 사용자별 구매행동에 따라 거래활동 전문가와 거래가치 전문가의 반영
강도를 다르게 한다.

## 2. CLV 사용자 표현

### 2.1 거래활동 축

`e_N(u)`는 사용자의 미래 거래횟수 `N_hat_u(H)`를 예측하는 중간 표현이다.

- 핵심 입력: Recency, Frequency, 관찰기간 `T`, 평균 구매간격 `AIT`
- 타깃: 예측기간 `H` 내 미래 거래횟수. 0회 가능성을 포함한 비조건부 기대값으로 학습한다.
- 해석: 생애전체 재구매횟수가 아니라 고정 예측기간의 거래활동 proxy다.

### 2.2 거래가치 축

`e_V(u)`는 사용자의 미래 거래당 구매금액 `V_hat_u`를 예측하는 중간 표현이다.

- 핵심 입력: 거래당 구매금액, 거래당 상품 수, 평균 상품단가
- 타깃: 미래 구매가 있는 경우의 거래당 평균 구매금액
- 해석: `V_hat`이 높다는 것은 한 번에 많이 지출한다는 뜻이지, 무조건 고가상품을
  선호한다는 뜻이 아니다. 거래당 상품 수와 평균 단가를 함께 사용해 저가 다품목과
  고가 소품목을 구분할 수 있게 한다.

### 2.3 CLV proxy

```
CLVProxy_hat_u(H) = N_hat_u(H) * V_hat_u
```

이 값은 이익·비용·할인율이 없는 공개 데이터에서의 **고정 예측기간 매출 기반 CLV
proxy**다. 실제 이익 CLV나 추천으로 증가한 CLV로 해석하지 않는다.

## 3. 아이템 이중축 표현

아이템은 CLV를 갖지 않는다. 아래는 각각 **아이템 활동속성**과 **아이템 경제속성**이다.

### 3.1 아이템 활동 표현 `e_N(i)`

- 구매 고객 수 백분위
- 고객별 반복구매 비율
- 반복구매가 있는 경우의 중앙 재구매 간격과 validity mask
- 카테고리 내 구매빈도 백분위. 전역 인기도 강화로 읽히지 않도록 전역값과 분리해 저장한다.

### 3.2 아이템 거래가치 표현 `e_V(i)`

- 전체 카탈로그 가격백분위
- 카테고리 내 가격백분위
- 평균 상품단가의 log 변환
- 거래 금액에서 해당 상품이 차지하는 평균 비율. 장바구니 식별자가 있는 Dunnhumby에서
  사용하고, H&M은 고객-날짜 단위 구매를 거래 proxy로 사용한다.

모든 속성은 공식 train 구간에서만 계산하고 validation/test 정보는 사용하지 않는다.

## 4. 고정 게이트와 점수식

유효 사용자 내 `N_hat`, `V_hat` 백분위를 각각 `q_N(u)`, `q_V(u)`로 두고 다음 고정 게이트를
사용한다.

```
g_N(u) = 2 * q_N(u)
g_V(u) = 2 * q_V(u)
```

각 게이트는 유효 사용자 평균이 약 1이고 범위가 0에서 2다. 학습형 gate network를 쓰지 않으므로
고객별 반영강도의 근거를 두 CLV 예측축으로 제한한다. 구매이력이 없는 사용자의 두 게이트는
0으로 둔다.

두 전문가의 임베딩은 L2 정규화하여 전문가별 점수 크기 차이가 게이트 비교를 압도하지 않게
한다.

```
S_base(u,i) = <z_u, z_i>
S_N(u,i) = <normalize(r_N_u), normalize(r_N_i)>
S_V(u,i) = <normalize(r_V_u), normalize(r_V_i)>

S(u,i) = S_base(u,i)
       + lambda * [g_N(u) * S_N(u,i) + g_V(u) * S_V(u,i)]
```

`S_base`는 외부 M1 선호점수로 항상 남긴다. `lambda=0`은 공통 M1과 정확히 같아야 한다.

## 5. 학습 경계

- 그래프: binary LightGCN, M1과 동일
- 손실: 균등 표본 plain BPR. CLV·거래가치 손실가중은 사용하지 않는다.
- negative sampling: M1과 동일한 uniform sampling
- 초기화: 외부 M1 checkpoint에서 시작
- M1은 전체 학습 기간 동결하고 두 전문가 adapter만 학습한다. 이로써 추가
  LightGCN 학습효과와 CLV 이중축 표현효과를 섬진히 분리한다.
- M1 해동 `joint_warm`은 고정 게이트 모형의 고유효과가 식별된 후속에만 확장모형으로
  다룬다.

## 6. 식별 대조군

모든 대조군은 동일한 입력차원·파라미터 수·초기화·학습예산을 사용한다.

| 모형 | 목적 |
|---|---|
| M1 | 외부 순수 LightGCN 기준 |
| `dual_clv_fixed` | 두 CLV 사용자 표현 + 두 아이템 표현 + 고정 게이트 |
| `dual_shuffled_gate` | 두 게이트 쌍을 유효 사용자 간 seed 42 순열 |
| `dual_base_only` | 두 사용자·아이템 추가입력을 0으로 두고 같은 어댑터 용량만 유지 |

기존 51차원 `single_full`은 일반 행동프로필 비교모형으로만 보고하며 새 CLV 제안모형의
필수 대조군으로 사용하지 않는다. `dual_equal_gate`, `dual_zero_N`, `dual_zero_V`도
현재 빠른 screening 범위에서 제외하고 후속 메커니즘 분석 후보로만 남긴다.

## 7. validation 선택과 성공 판정

- 1차: H&M 60일과 Dunnhumby에서 각각 seed 42 validation-only
- H&M 60일: 14일 입력, 7일 예측. 정확한 basket ID가 없으므로 고객-날짜를 거래 proxy로 사용
- Dunnhumby: `BASKET_ID`를 거래단위로 사용
- test·holdout은 열지 않는다.
- lambda 곡선은 `[0, 0.1, 0.25, 0.5, 1, 2]`를 모두 저장한다.
- 기존 비열등 screening 규칙과 비교 가능하게 Recall/NDCG@10·20·50의 M1 대비 상대하락
  1% 이내를 가드레일로 유지한다. 이는 학습 제약이 아니라 validation 사후 선택·판정 규칙이다.
- 위 조건을 통과하면서 M1보다 가격·구매금액 가중 적중값@10이 큰 양의 lambda 중 해당
  지표가 가장 큰 값을 선택한다. 없으면 lambda 0으로 돌아가되 성공으로 적지 않는다.
- 최종 screening 성공은 `dual_clv_fixed`가 M1 조건을 통과하고, 선택된 경제지표가
  `dual_shuffled_gate`, `dual_base_only`보다 크다는 두 조건을 모두 요구한다.

## 8. 저장·보고

기존 정확도·경제·노출지표와 다음을 함께 저장한다.

- 사용자별 `N_hat`, `V_hat`, `CLVProxy_hat`, `g_N`, `g_V`의 요약통계와 hash
- 세 CLV 세그먼트별 평균 `g_N/g_V`, Recall/NDCG, 가격·구매금액 가중 적중값
- 전문가별 raw/effective score 표준편차와 M1 점수 대비 비율
- 추천 상품 절대 수, Coverage, exposure entropy/effective catalog size, 상위 10·100 노출점유율
- M1 대비 사용자 대응 bootstrap 차이, 전체 lambda 절대곡선, 모든 불리한 결과
- 소스·데이터·M1·임베딩·게이트·checkpoint fingerprint

## 9. 해석 한계

- `dual_clv_fixed`의 성공은 CLV 구성축을 조건으로 추천 표현이 개선됐다는 뜻이지, 실제
  생애가치가 증가했다는 뜻이 아니다.
- H&M 60일 결과는 짧은 창의 파이프라인·메커니즘 screening이며 2년 결과를 대체하지 않는다.
- 게이트는 학습되지 않으므로 사용자별 반영강도는 해석 가능하지만, 고정 백분위 함수가 최적
  배분이라는 보장은 없다. 학습형 gate는 이 모형의 고유효과가 식별된 뒤에만 후속 확장으로
  다룬다.
