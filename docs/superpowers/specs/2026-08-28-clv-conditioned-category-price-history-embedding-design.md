# CLV 조건부 구매이력–후보상품 표현 M2 설계

작성일: 2026-08-28  
상태: 사용자 승인 후 구현 전 고정 명세  
연구축: M2 임베딩·표현 개입

## 1. 연구 질문

학습기간 구매행동으로 계산한 `historical CLV proxy`의 거래활동 수준과
거래당 가치 수준을 사용해, 고객의 과거 구매상품군 및 상품군 내 가격성향과
신규 후보상품의 관계를 하나의 작은 표현으로 학습하면 순수 LightGCN보다
신규상품 추천 정확도와 가격·구매금액 가중 적중값을 함께 개선할 수 있는가?

이 설계는 M2만 다룬다. M3 그래프 가중과 M4 손실 가중을 변경하지 않으며,
M2의 성공 여부와 관계없이 M3·M4는 동등한 사전 계획 연구축으로 유지한다.

## 2. 설계 근거

두 데이터셋의 M1 오차 진단에서 공통적으로 다음 현상이 확인됐다.

- M1의 Top-10 오추천은 누락 정답보다 훨씬 많은 고객이 구매한 상품이다.
- 누락 정답은 오추천보다 상품군 내 가격 위치가 높다.
- 중·고CLV 고객의 누락 정답은 대체로 고객이 과거에 구매한 큰 상품군 안에
  있지만, M1은 그 상품군 안에서 덜 대중적인 신규 후보를 구별하지 못한다.
- 같은 고CLV 고객도 거래활동에서 가치가 형성된 고객과 거래당 가치에서
  형성된 고객의 정확도와 가격·구매금액 가중 적중값이 다르다.

반면 기존 M2에서는 다음 문제가 반복됐다.

- N과 V를 독립 임베딩·독립 점수로 만들면 두 점수가 상쇄됐다.
- 원시 `RepeatShare` 등은 상품 인기도의 지름길로 작동했다.
- 학습형 전체 축 가중치는 특정 표현을 과도하게 확대했다.
- 자유 사용자 ID 임베딩의 작은 차원별 조절은 수치적으로 학습돼도 실제
  Top-K 순위를 거의 바꾸지 못했다.

따라서 이번 설계는 N/V를 독립 추천점수로 만들지 않는다. N/V를 함께 본
작은 혼합기가 고객의 구매상품군 관계와 상품군 내 가격성향 관계의 사용비율만
결정한다. 상품 인기도·구매고객 수·원시 반복구매 비율은 입력하지 않는다.

## 3. 고정 경계

- 평가 과업은 학습기간 구매쌍을 정답에서 제외한 신규상품 추천이다.
- `MIN_USER_INTER=1`, `MIN_ITEM_INTER=1`을 유지한다.
- 그래프는 M1과 같은 binary user–item graph다.
- negative sampling은 uniform이다.
- 모든 BPR 표본의 가중치는 1이다.
- 목적함수는 기존 plain pairwise BPR와 기존 sampled L2뿐이다.
- 사용자·상품 ID 임베딩, 상품군 표현, N/V 혼합기는 하나의 학습 루프와
  하나의 optimizer에서 함께 학습한다.
- 완성된 M1 점수에 외부 점수를 더하거나 재정렬하지 않는다.
- 현재 CLV는 미래 CLV가 아니라 학습기간 구매행동의 `historical CLV proxy`다.
- 개발 중에는 역사적 개발구간만 사용하고 최종 test와 holdout을 생성하지 않는다.

| 개념 | Dunnhumby | H&M |
|---|---|---|
| 거래 1회 | `BASKET_ID` | 같은 고객·같은 날짜의 구매 묶음 |
| 상품군 | `COMMODITY_DESC` | `product_type_name` |
| 상품가격 | `SALES_VALUE / QUANTITY`의 train 평균 | train 거래가격 평균 |
| 가격 위치 | 상품군 내 train 상품가격 백분위 | 상품군 내 train 상품가격 백분위 |

H&M의 `product_group_name`은 18개로 너무 거칠기 때문에 사용하지 않는다.
두 데이터셋에서 상품군의 개수는 달라도, 동일하게 "후보상품이 속한 비교
가능한 상품유형"이라는 역할을 사용한다.

모든 통계는 해당 실행의 학습구간만으로 계산하고 평가구간 정보는 사용하지 않는다.

## 5. 사용자 거래활동 수준

사용자 `u`의 학습기간 거래횟수를 `B_u`, 첫 거래일부터 학습종료일까지의
관찰일수를 `T_u`, 학습종료일부터 마지막 거래까지의 경과일을 `Recency_u`,
서로 다른 거래 사이의 평균 간격을 `Gap_u`라 한다.

원시 행동변수는 다음과 같다.

\[
F_u^{raw}=\frac{\max(B_u-1,0)}{\max(T_u,1)}
\]

\[
R_u^{raw}=1-\min\left(\frac{Recency_u}{\max(T_u,1)},1\right)
\]

\[
G_u^{raw}=\frac{1}{1+Gap_u}
\]

각 변수는 유효한 train 사용자 모집단에서 평균동점 백분위로 바꾼다.

\[
F_u=Pct(F_u^{raw}),\quad R_u=Pct(R_u^{raw}),\quad G_u=Pct(G_u^{raw})
\]

거래활동 수준은 계산 가능한 변수의 산술평균이다.

\[
\widehat N_u=Mean_{available}(F_u,R_u,G_u)
\]

거래가 한 번뿐이면 `Gap_u`는 계산하지 않고 나머지 유효변수만 평균한다.
세 변수를 모두 계산할 수 없는 사용자는 N축 계산불가로 둔다.

## 6. 사용자 거래당 가치 수준

사용자 총 구매금액을 거래횟수로 나눈 거래당 평균 구매금액을 `AOV_u`라 한다.
상품 `i`의 상품군 내 가격 백분위를 `PricePct_i^{cat}`라 한다. 같은 거래에
여러 상품이 있으면 거래 안에서 먼저 평균하고, 이후 사용자 거래 전체에서
평균해 구매행이 많은 거래가 과도하게 반영되지 않게 한다.

\[
A_u=Pct(AOV_u)
\]

\[
P_u=Pct\left(Mean_{transaction}\left[
Mean_{item\ in\ transaction}(PricePct_i^{cat})
\right]\right)
\]

거래당 가치 수준은 계산 가능한 두 변수의 산술평균이다.

\[
\widehat V_u=Mean_{available}(A_u,P_u)
\]

두 변수를 모두 계산할 수 없는 사용자는 V축 계산불가로 둔다.

## 7. 추천모형에 전달하는 고객가치 상태

\[
c_u=
[\widehat N_u,\widehat V_u,
  \widehat N_u\widehat V_u,
  \widehat N_u-\widehat V_u]
\]

- `N_hat`: 거래활동 수준
- `V_hat`: 거래당 가치 수준
- `N_hat × V_hat`: 전체 historical CLV proxy
- `N_hat − V_hat`: 가치가 주로 어느 축에서 형성됐는지 나타내는 구성 차이

N 또는 V가 계산불가이면 해당 사용자의 전체 보조 표현을 0으로 두고 ID
경로만 사용한다. 평가 성과를 보고 결측 대체값을 조정하지 않는다.

## 8. 고객 구매이력 표현

사용자 `u`가 학습기간에 구매한 서로 다른 상품 중 상품군 `c`에 속한 상품
수를 `n_uc`라 하고 사용자 안에서 정규화한다.

\[
p_{u,c}=\frac{n_{u,c}}{\sum_d n_{u,d}}
\]

같은 상품의 반복구매는 한 번으로 센다. 따라서 반복구매가 많은 인기상품이나
큰 장바구니가 사용자 표현의 크기를 기계적으로 키우지 않고, 신규상품 추천에
필요한 사용자의 과거 상품영역을 나타낸다. 이 정의는 BPR 양성상품 하나의
기여를 학습 중 정확히 빼는 leave-one-out도 가능하게 한다.

상품군마다 공동학습되는 4차원 벡터 `e_c`를 두고 forward에서 단위벡터로
정규화한다.

\[
\bar e_c=\frac{e_c}{\max(\lVert e_c\rVert_2,\epsilon)}
\]

사용자의 구매상품군 표현은 다음과 같다.

\[
h_u^{category}=\sum_c p_{u,c}\bar e_c
\]

사용자 `u`가 상품군 `c`에서 산 서로 다른 상품들의 중심화 가격 위치 평균을
`r_uc`라 한다. 같은 상품의 반복구매는 가격성향 평균에서도 한 번으로 센다.

\[
r_{u,c}=Mean_{i\ purchased\ by\ u,\ c_i=c}
(2PricePct_i^{cat}-1)
\]

사용자의 상품군별 가격성향 표현은 다음과 같다.

\[
h_u^{price}=\sum_c p_{u,c}r_{u,c}\bar e_c
\]

## 9. 후보상품 표현

후보상품 `i`의 중심화 가격 위치를 다음과 같이 둔다.

\[
r_i=2PricePct_i^{cat}-1
\]

후보상품의 두 표현은 다음과 같다.

\[
h_i^{category}=\bar e_{c_i}
\]

\[
h_i^{price}=r_i\bar e_{c_i}
\]

후보상품별 자유 보조 임베딩은 만들지 않는다. 동일 상품군·유사 가격 위치의
상품은 보조공간에서는 유사하게 보되, 개별 상품 차이는 기존 ID 임베딩이
학습한다.

가격이 없거나 유효하지 않으면 해당 상품의 `r_i=0`으로 두며, 상품군이
없으면 train에만 존재하는 `UNKNOWN` 상품군을 사용한다.

## 10. N/V의 공동 조건화

고객가치 상태에서 두 구매이력 관계의 혼합비를 만든다.

\[
[\alpha_u,\beta_u]=softmax(Wc_u+b)
\]

`W`는 `2×4`, `b`는 2차원으로 총 10개 파라미터만 갖는다. `W`와 `b`는
0으로 초기화해 최초에는 모든 유효 사용자에게 `alpha=beta=0.5`가 되게 한다.

\[
h_u^{aux}=
[\alpha_u h_u^{category}\mid\beta_u h_u^{price}]
\]

\[
h_i^{aux}=
[h_i^{category}\mid h_i^{price}]
\]

N과 V는 독립된 상품점수를 만들지 않는다. 두 값을 함께 본 제한된 혼합기가
상품군 관계와 상품군 내 가격관계를 얼마나 사용할지만 결정한다.
`alpha+beta=1`이므로 두 관계의 반영량이 동시에 무제한으로 커질 수 없다.

## 11. 양성상품 자기참조 방지

BPR 양성상품 `i+`가 사용자 구매이력 표현에 그대로 들어가면 보조표현이
정답을 미리 포함한다. 학습 배치에서는 양성상품의 기여를 사용자 이력에서
제외한 leave-one-out 표현을 사용한다.

\[
h_{u,-i^+}^{category},\qquad h_{u,-i^+}^{price}
\]

같은 leave-one-out 사용자 표현으로 양성상품과 음성상품을 비교한다.
평가 후보는 학습기간에 구매하지 않은 신규상품이므로 평가에서는 train 전체
구매이력을 사용한다.

학습 고유상품이 하나뿐인 사용자는 leave-one-out 이후 이력이 0이 된다.
학습·평가 불일치를 막기 위해 이런 사용자의 보조표현은 평가에서도 0으로
고정하고 ID 경로만 사용한다. 데이터셋별 해당 사용자 수와 비율을 저장한다.

## 12. LightGCN 초기 표현과 전파

ID는 64차원, 보조표현은 상품군 4차원과 가격성향 4차원으로 총 72차원이다.
초기 탐색에서는 `rho=0.1` 하나를 결과 확인 전에 고정한다.

\[
E_u^{(0)}=
[E_u^{ID}\mid\sqrt{\rho}\,h_u^{aux}]
\]

\[
E_i^{(0)}=
[E_i^{ID}\mid\sqrt{\rho}\,h_i^{aux}]
\]

72차원 전체를 M1과 같은 정규화 이진 인접행렬로 2층 전파한다.

\[
E^{(l+1)}=\widehat A E^{(l)}
\]

\[
Z=\frac{1}{3}(E^{(0)}+E^{(1)}+E^{(2)})
\]

\[
S(u,i)=Z_u^\top Z_i
\]

`rho`는 layer-0 보조표현의 고정 초기 배율이다. 그래프 전파 뒤의 실제 점수
기여 상한이라고 과장하지 않고, 실제 `std(S_aux)/std(S_ID)`를 별도 기록한다.

최종 내적은 수학적으로 ID 부분과 하나의 보조 부분으로 분해할 수 있다.
이번 변경의 차이는 덧셈 자체를 없애는 것이 아니라, N과 V의 독립점수 두 개를
없애고 N/V를 하나의 제한된 후보 적합 표현 안에서 먼저 결합하는 것이다.

## 13. 학습

\[
L_{BPR}=-\log\sigma(S(u,i^+)-S(u,i^-))
\]

기존 sampled layer-0 L2 외의 손실항은 추가하지 않는다. 사용자·상품 ID,
상품군 벡터, 10개 혼합기 파라미터를 같은 BPR gradient와 optimizer로
공동학습한다. CLV 기반 표본가중이나 hard negative를 사용하지 않는다.

## 14. 최초 탐색 실험

| 항목 | 고정값 |
|---|---|
| 데이터 | Dunnhumby |
| 구간 | DAY 1~683 학습, DAY 684~690 역사적 개발평가 |
| seed | 42 |
| epoch | 100 고정, checkpoint 선택 없음 |
| comparator | 저장된 동일 구간 M1@64 |
| rho | 0.1 |
| graph | binary |
| negative sampling | uniform |
| sample weighting | 없음 |
| test/holdout | 생성하지 않음 |

탐색 판독은 다음처럼 사전 고정한다.

1. 가격·구매금액 가중 적중값@10이 M1보다 커야 한다.
2. Recall/NDCG@10·20·50이 각각 M1의 99% 이상이어야 한다.
3. `rho=0` 점수 계산이 같은 ID state의 M1과 수치적으로 일치해야 한다.

세 조건을 통과하면 탐색 양성으로 분류하되, 단일 seed이므로 유의성·일반화를
주장하지 않는다. 가격·구매금액 가중 적중값과 여섯 정확도가 모두 M1보다
높은 경우만 강한 탐색 양성으로 별도 표기한다.

## 15. 양성 결과 이후 대조군

최초 탐색이 양성일 때만 다음 순서로 진행한다.

1. 같은 총차원의 순수 협업 대조군 M1@72
2. 사용자 `c_u`를 유효 사용자 사이에서 고정 순열로 섞은 대조군
3. 보조표현을 끈 ID-only checkpoint view
4. 여러 seed
5. 설정을 동결한 뒤 H&M 2년 동일 구조 실행

M2가 M1@64만 이기고 M1@72를 이기지 못하면 추가 용량 효과를 배제할 수
없다고 기록한다. 실제 사용자 배정이 shuffled 대조군을 이기지 못하면 CLV
조건화 효과를 주장하지 않는다.

## 16. 필수 진단

- `alpha`, `beta`의 평균·표준편차·최솟값·최댓값
- `alpha`와 `N_hat`, `V_hat`, `N_hat×V_hat`, `N_hat−V_hat`의 상관
- `std(S_aux)/std(S_ID)`
- M1 대비 Top-10·20·50 목록 변경 사용자 비율
- ID-only와 full의 Recall/NDCG 및 가격·구매금액 가중 적중값
- 새로 올라온 상품과 밀려난 상품의 상품군·상품군 내 가격 백분위·train 구매고객 수
- Top-10 노출 상품의 train degree와 노출횟수의 Spearman 상관
- 단일 고유상품 사용자 수와 보조표현 비활성화 비율
- 사용자별 보조표현 간 평균 cosine과 분산

`alpha`의 사용자 표준편차가 작고 shuffled와 동일하면 개인별 조건화가
작동하지 않은 것으로 해석한다. 점수비율과 Top-K 변경률이 거의 0이면 실효
개입 부족, 변경률은 충분하지만 지표가 하락하면 후보방향 오류로 분리한다.

## 17. 구현 전 검증 요구사항

- train-only 백분위와 가격통계가 평가행에 영향받지 않는 단위검사
- Dunnhumby/H&M 거래 1회 정의 검사
- 사용자 상품군 비중 행합 1 검사
- 상품군 내 가격 백분위 범위와 중심화 범위 검사
- 양성상품 leave-one-out 검사
- 단일 고유상품 사용자의 학습·평가 보조표현 0 일치 검사
- `rho=0` M1 점수 동일성 검사
- category embedding과 혼합기까지 BPR gradient가 전달되는지 검사
- M3 그래프가중·M4 표본가중·새 손실항이 없다는 설정검사
- 결과 파일에 데이터 구간·seed·rho·차원·source revision·진단값 저장 검사

## 18. 한계와 정직한 해석

- 이 모형은 미래 CLV를 예측하거나 추천으로 CLV가 증가했다고 주장하지 않는다.
- 상품군과 가격 위치만으로 모든 신규상품 차이를 설명할 수 없다.
- binary LightGCN과 uniform negative sampling에 존재하는 기본 인기도 편향을
  제거하는 모형은 아니다. M2가 그 편향을 추가로 강화하지 않는지를 진단한다.
- layer-0에 고정한 `rho`는 전파 후 실제 점수기여의 엄밀한 상한이 아니다.
- 단일 seed 역사적 개발결과는 구조 탐색이며 유의성이나 일반화 근거가 아니다.
