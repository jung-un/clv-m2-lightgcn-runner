# M4 CLV 조건부 다중 음성 BPR 설계

## 1. 연구축과 질문

이 설계는 M1~M5 중 **M4 손실함수 개입**에 해당한다. M2 임베딩과 M3
그래프 개입은 사용하지 않고, M1의 사용자·상품 ID 임베딩, 이진 그래프,
LightGCN 전파는 그대로 둔다.

연구질문은 다음과 같다.

> 동일하게 무작위 추출한 여러 미관측 상품 중에서, historical CLV proxy가
> 높은 고객일수록 현재 양성상품과 구별하기 어려운 음성상품에 더 집중해
> BPR을 학습하면 일반 추천 정확도를 보존하면서 고CLV 고객의 신규상품
> 순위와 가격·구매금액 가중 적중값을 개선할 수 있는가?

이 질문은 고객가치가 높은 사용자의 모든 학습표본에 더 큰 총가중치를 주는
기존 M4와 다르다. 고객별 전체 손실량은 같게 유지하고, 한 양성표본 내부의
여러 음성상품 사이에서 학습 집중도만 바꾼다.

## 2. 이전 M4 실패에서 바꾸는 점

기존 M4는 사용자 CLV 또는 관측된 양성상품의 거래기여도를 표본가중치로
사용했다. 그러나 신규상품 추천에서는 학습기간의 관측상품 자체가 평가
정답에서 제외된다. 따라서 관측표본의 손실을 크게 하는 것만으로는 어떤
미관측 상품을 다음 정답으로 구별해야 하는지 직접 학습하기 어렵다.

이번 설계는 다음 원칙을 고정한다.

1. 고객별 전체 손실질량을 CLV에 따라 키우지 않는다.
2. 양성상품의 가격·금액을 손실가중치로 사용하지 않는다.
3. negative sampling 분포는 M1과 같은 uniform으로 유지한다.
4. 한 양성표본에 대해 `K=5`개의 uniform 음성을 뽑고, CLV는 이 다섯
   손실의 **배분**에만 사용한다.
5. 새로운 보조손실을 추가하지 않고 BPR 손실 하나만 사용한다.
6. N/V는 M4 손실 안에서 별도 축으로 쓰지 않는다. 전체 historical CLV
   수준만 학습 집중도를 정하고, N/V 구성은 결과 세그먼트 진단에 사용한다.

## 3. 고정 historical CLV 입력

사용자 `u`의 학습기간 행동으로 기존 연구 정의의 historical CLV proxy를
계산한다.

\[
C_u^{hist}=\widehat N_u\widehat V_u
\]

train 사용자 분포에서만 백분위로 변환한다.

\[
q_C(u)=\operatorname{Percentile}_{train}(C_u^{hist})\in[0,1]
\]

`q_C`는 미래 CLV나 추천 후 증가한 가치를 의미하지 않는다. 평가 시에도
학습기간에서 고정한 값을 사용한다. 계산 불가능한 사용자는 유효성 마스크를
적용하고 비개입 값 `q_C=0`으로 둔다.

## 4. 모델과 다중 음성 BPR

### 4.1 M1 표현과 점수

사용자와 상품의 64차원 자유 ID 임베딩을 하나의 이진 사용자–상품 그래프에서
2층 전파한다.

\[
E^{(l+1)}=\widehat A E^{(l)},\qquad
z=\frac{1}{3}\left(E^{(0)}+E^{(1)}+E^{(2)}\right)
\]

점수는 M1과 동일하다.

\[
S(u,i)=z_u^\top z_i
\]

M4는 표현이나 그래프를 바꾸지 않는다.

### 4.2 동일 양성표본의 다섯 uniform 음성

양성쌍 `(u,i^+)`마다 학습기간에 관측되지 않은 상품 중 `K=5`개를
독립적으로 uniform 추출한다.

\[
j_1,\ldots,j_K\sim Uniform(\mathcal I\setminus\mathcal I_u^{train})
\]

각 음성상품의 BPR 손실은 다음과 같다.

\[
\ell_k(u,i^+,j_k)
=-\log\sigma\left(S(u,i^+)-S(u,j_k)\right)
\]

가장 구별하기 어려운 음성은 현재 점수가 가장 높은 상품이다.

\[
k^*=\arg\max_k S(u,j_k)
\]

`argmax` 선택에는 gradient를 흘리지 않고, 선택된 BPR 손실을 통해서만
gradient가 흐른다.

### 4.3 CLV 조건부 손실 배분

각 음성 손실의 가중치는 다음과 같다.

\[
a_{u,k}=\frac{1-q_C(u)}{K}+q_C(u)\mathbf 1[k=k^*]
\]

최종 한 행의 손실은 다음과 같다.

\[
\mathcal L_u=\sum_{k=1}^{K}a_{u,k}\ell_k
\]

이때 항상

\[
\sum_{k=1}^{K}a_{u,k}=1
\]

이므로 고CLV 고객이라고 해서 총 손실량이 커지지 않는다.

- `q_C=0`: 다섯 음성의 평균 BPR
- `q_C=1`: 현재 가장 어려운 음성 하나의 BPR
- `0<q_C<1`: 평균 학습과 어려운 음성 학습의 고정 볼록결합

따라서 CLV는 “누구의 데이터를 더 크게 학습할 것인가”가 아니라 “같은
고객의 후보 구별 중 어디에 더 집중할 것인가”를 정한다.

### 4.4 기존 L2의 스케일

기존 sampled L2는 사용자와 양성 임베딩에 대해 한 번, 다섯 음성 임베딩에
대해서는 평균을 사용한다. `K`가 늘었다는 이유만으로 정규화 강도가 다섯 배
커지지 않게 한다. 새 정규화항은 추가하지 않는다.

## 5. 실험 arm

빠른 1차 역사적 개발 실험은 다음 세 arm으로 구성한다.

1. `m1_k1`: 기존 M1, 양성당 uniform 음성 1개. 저장된 seed 42 성과를
   표시용 기준으로 재사용한다.
2. `m1_multineg_mean_k5`: 동일 M1 표현, uniform 음성 5개, 다섯 BPR의
   단순평균. 다중 음성 자체의 효과를 통제한다.
3. `m4_clv_hard_k5`: arm 2와 동일한 다섯 음성을 사용하고 위 CLV 조건부
   손실배분만 적용한다.

arm 2와 3은 같은 초기화 순서, 같은 미니배치 순서, 같은 음성행렬을 사용한다.
따라서 두 arm의 차이는 CLV 조건부 손실배분뿐이다.

## 6. 고정 실험 조건

- 데이터: Dunnhumby
- seed: 42
- 학습구간: day 1~683
- 개발평가: day 684~690 신규상품 추천
- 최종 test와 holdout: 생성·평가하지 않음
- 학습구간의 기존 `(user,item)` 쌍: 평가 정답과 후보에서 제외
- 그래프: binary, M1과 동일
- LightGCN: ID 64차원, 2층, 0·1·2층 단순평균
- negative sampling: uniform
- 최소 아이템 상호작용: 1
- 학습 epoch: 100 고정
- validation 기반 epoch 선택: 없음
- optimizer와 학습루프: 각각 하나
- M2 사용자·상품 속성 입력: 없음
- M3 엣지가중: 없음
- 가격·구매금액 기반 표본가중: 없음
- 외부 재정렬: 없음

## 7. 사전 판정 규칙

`m4_clv_hard_k5`는 다음을 모두 만족해야 1차 탐색을 통과한다.

1. 전체 Recall/NDCG@10·20·50이 기존 `m1_k1`의 각각 99% 이상
2. 고CLV Recall@10과 NDCG@10이 `m1_multineg_mean_k5`보다 모두 증가
3. 전체 가격·구매금액 가중 적중값@10이 `m1_k1`과
   `m1_multineg_mean_k5`보다 모두 증가
4. Coverage@10과 추천상품 수가 `m1_k1`의 95% 이상
5. Top-10 집중도는 `m1_k1`의 105% 이하

단일 seed 탐색이므로 통계적 유의성을 주장하지 않는다. 하나라도 미달하면
1차 판정은 실패다.

## 8. 통과 후 CLV 고유 기여 대조군

1차 탐색이 통과한 경우에만, 사용자 활동량이 비슷한 고객 안에서 `q_C`를
순열한 대조군을 추가한다. 단순 shuffled-user보다 CLV와 사용자 degree의
중첩을 더 엄격하게 통제한다.

정상 CLV 배정은 degree-matched 순열보다 다음 세 지표가 모두 좋아야 한다.

- 고CLV Recall@10
- 고CLV NDCG@10
- 전체 가격·구매금액 가중 적중값@10

이후에만 개발용 여러 seed와 H&M 2년 validation으로 넘어간다. Dunnhumby와
H&M에서 같은 `K=5`와 같은 손실식을 사용한다.

## 9. 필수 작동 진단

성과 해석 전에 다음을 저장한다.

- 전체 및 저·중·고CLV별 평균 `q_C`
- 전체 및 CLV 구간별 가장 어려운 음성에 배정된 평균 가중치
- 행별 가중치 합의 최대 오차
- `q_C=0` 행이 정확히 다중 음성 평균 BPR과 일치하는지
- `q_C=1` 행이 정확히 가장 어려운 음성 BPR과 일치하는지
- `K=1`일 때 기존 BPR과 정확히 일치하는지
- CLV 구간별 양성–최고점 음성 점수차
- CLV 구간 및 N우세·균형·V우세 고CLV 구성별 Recall/NDCG와
  가격·구매금액 가중 적중값
- arm 2와 arm 3의 학습 손실 및 sampled L2 스케일
- 잘못된 음성표본 수: 양성상품 또는 학습 관측상품과 충돌한 수

## 10. 오류 차단과 최소 테스트

실행 전 다음을 자동검사한다.

1. `q_C`의 shape, 유한값, `[0,1]` 범위
2. `K=5` 고정
3. 모든 음성이 해당 사용자의 학습 관측상품이 아님
4. 행별 가중치 합이 `1±1e-6`
5. 가중치가 음수가 아님
6. arm 2와 arm 3이 동일 음성행렬을 사용함
7. 최종 test와 holdout이 구성되지 않음

단위테스트는 작은 고정 점수 예제로 다음 항등을 검증한다.

- `q_C=0` → 다섯 BPR 평균
- `q_C=1` → 최고점 음성 BPR
- `K=1` → 기존 plain BPR
- 중간 `q_C` → 두 손실의 정확한 볼록결합
- 다섯 음성을 평균낸 sampled L2가 `K`에 비례해 커지지 않음

## 11. 해석 한계

- uniform으로 뽑은 미관측 상품은 실제 부정선호가 아니라 아직 관측되지 않은
  상품일 수 있다. `K=5`로 제한하고 일반 정확도 가드를 두는 이유다.
- 개선이 나더라도 CLV가 선호정보를 새로 표현했다고 해석하지 않는다. M4는
  historical CLV 수준에 따라 **후보 구별 학습의 집중도**를 바꾼 결과다.
- `m1_multineg_mean_k5`도 개선되면 그 부분은 CLV 효과가 아니라 다중 음성
  학습 효과다.
- 정상 `q_C`가 degree-matched 순열을 이기지 못하면 CLV 고유 기여를
  주장하지 않는다.
- 이 실행은 개발용 탐색이며 최종 test 결과로 모형을 다시 조정하지 않는다.
